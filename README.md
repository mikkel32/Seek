# Seek

A chess engine research project built from scratch. Two systems, and a line of work in which the engine teaches
itself from the rules alone.

- **OURO** — a 2,054,635-parameter looped transformer (`model.py`). Two input blocks, three blocks that are run
  1 to 4 times with shared weights, two output blocks; attention is biased by nine exact rule planes (who attacks
  whom, lines, pins); heads for the move, the outcome and the value of every move. Trained with Muon + AdamW.
- **CALC** — a bitboard alpha-beta engine in one C file (`calc/calc.c`) with a small evaluation network
  (768 piece-square inputs → hidden layer per side → 8 piece-count heads, on top of an exactly solved
  piece-square table). Lazy incremental accumulators, AVX-512 / AVX2, PEXT sliding attacks.
- **The self-taught line** (`zero/`) — CALC starting from "count my moves minus yours", solving its first
  evaluation tables exactly from its own game results, then training networks on its own self-play. Nothing from
  any other engine is learned from. Stockfish is used only as a ruler. Details: [`zero/README.md`](zero/README.md).

The full account of the first phase (design, ablations, the weight-space-programming run, ratings) is in
[`REPORT.md`](REPORT.md).

## Results so far

Ratings are measured against Stockfish 16 at limited strength (`elo_ladder.py`). **There are two scales and they
are not interchangeable**: *time-based* (both sides 0.1 s per move, depends on the machine) and *node-based*
(both sides 100,000 nodes per move, the same on any machine). The node-based scale reads roughly 500 lower.

| Engine | Rating | Scale |
|---|---|---|
| OURO alone, no search | 1498 ± 50 | time |
| OURO + 64-node tree search | 1748 ± 62 | time |
| CALC, taught from Stockfish evaluations | 2716 ± 55 | time |
| Self-taught, generation 1 (solved table) | 1515 ± 76 | time |
| Self-taught, generation 3 | 2360 ± 73 | time |
| Self-taught, generation 5 | 2521 ± 59 | time |
| Self-taught, generation 5 | 1988 ± 79 | nodes |
| Self-taught, generation 6 (small machine's network) | 2577 ± 57 | time |
| Self-taught, generation 6 (rented machine's network) | 2119 ± 60 | nodes |

Head to head at equal nodes on the rented machine: generation 6 beat 5 by +135, 7 beat 6 by +21 (−22 to +64),
8 beat 7 by +54 (+11 to +99), 9 against 8 was level (+3, −40 to +47).

Full-strength Stockfish is roughly 1,000 Elo above the best of these. That is the honest distance.

## Layout

```
model.py engine.py train.py wsp.py        OURO: model, tree search, training, weight-space programming
match.py elo_ladder.py bench.py uci.py    matches, rating ladder, puzzle test, UCI front ends
calc/calc.c                               CALC, current source (older versions kept beside it)
calc/train_nnue.py solve_pst.py ...       evaluation training, exact table solve, checks
zero/loop.py                              self-taught loop, one generation at a time
zero/cont.py                              continuous version: self-play never stops, sliding window, GPU trainer
zero/ouro_gpu.py                          OURO learning from CALC's self-play on a GPU
zero/nodes_exp.py width_exp.sh spsa.py    experiments: nodes per move, network width, self-tuned search
zero/g1..g6.*                             self-taught networks made on the small machine
zero/box/                                 networks, logs and ratings from the rented 42-thread machine
ckpt/                                     OURO checkpoints A and B
logs/                                     match and rating results (JSON)
```

## Build and run

```bash
gcc -O3 -march=native -funroll-loops -o calc/calc_z5 calc/calc.c -lm
```

Add `-DNO_PEXT` on CPUs with slow PEXT (AMD Zen 1 and 2).

```bash
python3 match.py --a calc:zero/box/g9.bin:10000:calc/calc_z5 --b calc:zero/g5.bin:10000:calc/calc_z5 --openings 100 --workers 4
```

```bash
python3 elo_ladder.py --player calc:zero/box/g9.bin:100000:calc/calc_z5 --sf_time 100000 --openings 20 --levels 3 --workers 4
```

```bash
NPROC=42 python3 zero/cont.py
```

Python needs `torch`, `numpy` and `python-chess`; the rating ladder needs a `stockfish` binary on the path.
